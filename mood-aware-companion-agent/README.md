# 🎧 Mood-Aware Creative Companion Agent

A lightweight AI agent that helps users quickly find the **right music and creative inspiration** based on their **current activity, mood, and preferred language/region** — without wasting time browsing playlists.

---

## 🧩 Problem Statement

While sketching, coding, or relaxing, users often:
- Struggle to find **music that matches their mood**
- Need **focus, creativity, or calm**
- Waste time **scrolling through playlists or apps**

This agent solves that by providing **instant, context-aware recommendations**.

---

## 🎯 Solution Overview

The **Mood-Aware Creative Companion Agent** interacts with the user using a few simple questions and generates **personalized music and inspiration suggestions**.

---

## 🛠️ How It Works

The agent asks the user **three quick questions**:

1. **What are you doing?**
   - Sketching
   - Coding
   - Relaxing
   - Workout

2. **How do you feel?**
   - Calm
   - Low
   - Energetic

3. **Preferred region, language, or music type**
   - Example: Hindi, Telugu, English, Korean, Instrumental, etc.

Based on these inputs, the agent recommends:
- 🎵 **Music names categorized by specific genres**
- 🎬 **If the current activity is 'Relaxing' then it can recommend Movie or short-films as well**

---

## ✨ Features

- 🎨 **Activity-based recommendations**  
  Suggests music tailored for sketching, coding, workouts, or relaxation.

- 🧠 **Mood-aware suggestions**  
  Adapts recommendations for focus, energy, or calmness.

- 🌍 **Region / language preference support**  
  Allows users to choose music in their preferred language or regional style.

- ⚡ **Fast & minimal interaction**  
  No long questionnaires — just 3 simple inputs.

- 🧩 **Lightweight & easy to extend**  
  Can later be expanded with playlists, APIs, or memory.
